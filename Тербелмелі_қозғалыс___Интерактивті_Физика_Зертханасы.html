Гармоникалық Тербелістердің Синусоида Графиктері

Ығысу x(t), жылдамдық v(t) және үдеу а(t) параметрлерінің уақытқа тәуелділік графигі.

Фазалық ығысу ережесі:

• Ығысу x(t) максималды болғанда, Жылдамдық v(t) 0-ге тең болады.
• Үдеу a(t) әрқашан ығысуға қарама-қарсы бағытталған (a = -ω²x).

Практикалық Тапсырмалар: 5 Стандартты Емес Есеп

Бұл бөлімде формуланы жайдан-жай қоя салу емес, терең физикалық мағынаны, контекстті және логиканы талап ететін есептер жинақталған.

1-Есеп: Космостық маятникті сағат g_Жер = 9.81 м/с², g_Ай = 1.62 м/с²

Жерде маятникті сағаттың периоды T₁ = 2.0 с болып тура дәл жүреді. Астронавттар осы сағатты Айға (g_Ай = 1.62 м/с²) алып келді. Жердің 1 сағаты (60 минут) өткенде, Айда тұрған бұл сағат циферблаты қанша минутты көрсетеді? (Жауапты минутпен дөңгелектеп жазыңыз).

2-Есеп: Жеделдетілген лифттегі маятник L = 1.0 м, a = 2.19 м/с², g = 9.81 м/с²

Ұзындығы L = 1.0 м математикалық маятник лифт ішіне ілінген. Лифт жоғары қарай a = 2.19 м/с² тұрақты үдеумен көтеріле бастады. Лифт ішіндегі маятниктің тербеліс периоды (T_эфф) неше секундқа тең болады? (Жауапты жүздік үлеске дейін дөңгелектеңіз).

3-Есеп: Резонанс және көпірдің қауіпсіздігі L = 2.5 м, g = 9.81 м/с²

Үлкен аспалы көпірдің меншікті тербеліс периоды ұзындығы L = 2.5 м математикалық маятниктің периодына сәйкес келеді. Сол көпір үстінен әскери рота саппен өтіп бара жатыр. Қауіпті РЕЗОНАНС құбылысы орын алмас үшін әскер сабының адымдау жиілігі (f) қандай мәннен алшақ болуы тиіс?

4-Есеп: Энергия тепе-теңдік сәтіндегі жылдамдық A = 0.20 м, f = 5.0 Гц

Гармоникалық тербеліс жасайтын жүк амплитудасы A = 0.20 м және жиілігі f = 5.0 Гц. Кинетикалық энергия Потенциалдық энергияға дәл тең болған (Eₖ = Eₚ) сәттегі дененің жылдамдығын (v) табыңыз. (м/с есебімен жүздікке дейін).

5-Есеп: Фазалардың қайта беттесуі L₁ = 1.00 м, L₂ = 0.25 м

Ұзындықтары L₁ = 1.00 м және L₂ = 0.25 м болатын екі математикалық маятник бір мезетте бір тарапқа қарай ауытқытылып босатылды. Ұзын маятник (L₁) қанша толық тербеліс жасаған кезде екі маятник алғаш рет қайтадан бастапқыдай бірдей фазаға келеді?

Тербелмелі Қозғалыс Теориясы

9-сынып Физика курсы: Гармоникалық тербелістер, период, жиілік, энергия түрленуі және резонанс.

Негізгі Сипаттамалар

  • • Период (T): Толық бір тербеліс жасауға кеткен уақыт: T = t / N (секунд, с).
  • • Жиілік (ν немесе f): 1 секундтағы тербелістер саны: f = N / t = 1 / T (Герц, Гц).
  • • Циклдік жиілік (ω): 2π секундтағы тербелістер саны: ω = 2πf = 2π / T (рад/с).
  • • Амплитуда (A немесе xm): Дененің тепе-теңдік қалыптан ең үлкен ығысуы (метр, м).

Маятниктердің Меншікті Периоды

Математикалық: T = 2π √(L / g)
Серіппелі: T = 2π √(m / k)

*Математикалық маятник периоды жүк массасына тәуелсіз, ал серіппелі маятник периоды гравитацияға (g) тәуелсіз!

⚡ Еріксіз Тербелістер және Резонанс Құбылысы:

Резонанс — мәжбүрлеуші сыртқы күштің жиілігі тербелмелі жүйенің меншікті жиілігіне (f = f₀) сәйкес келген кезде тербеліс амплитудасының кенеттен күрт арту құбылысы.

⚠️ Тәжірибелік маңызы: Көпірлер салу, ғимараттарды жер сілкінісінен қорғау, музыкалық аспаптардың резонаторлары.
